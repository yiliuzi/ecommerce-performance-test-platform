# 电商接口性能测试报告

## 1. 报告概述

本次测试使用Locust对电商接口执行基准、阶梯、混合业务、峰值和稳定性测试，并通过Prometheus与Grafana监控请求速率、响应时间、错误率及API进程资源使用情况。

测试目标包括：

- 建立接口性能基线。
- 验证系统在100并发用户下的稳定性。
- 探索高并发场景下的系统容量边界。
- 定位数据库连接池相关性能瓶颈。
- 验证优化措施对吞吐量和长尾响应时间的影响。

## 4. 分场景分析

### 4.1 基准测试

在10用户低负载下共完成314次请求，无请求失败。

主要指标：

- 平均响应时间：5.37 ms
- P95：6 ms
- P99：9 ms
- 平均RPS：4.9
- 失败率：0%

结论：低负载下服务响应稳定，接口基础功能和性能正常。

### 4.2 阶梯负载测试

用户数逐步增加至100，共完成11,204次请求，无请求失败。

主要指标：

- 平均响应时间：29 ms
- P95：190 ms
- P99：250 ms
- 最大响应时间：401 ms
- 平均RPS：92.90
- 失败率：0%

结论：系统能够承受100用户阶梯负载，吞吐量随用户数增加而提升，未出现HTTP错误。

### 4.3 混合业务测试

混合测试覆盖商品查询、订单查询和订单创建，共完成1,162次请求，并成功创建55个测试订单。

主要指标：

- 平均响应时间：5.49 ms
- P95：10 ms
- P99：37 ms
- 最大响应时间：83 ms
- 平均RPS：19.50
- 失败率：0%

结论：读写混合场景运行稳定。测试结束后，根据记录的订单ID恢复商品库存并删除测试订单，未影响原有业务数据。
